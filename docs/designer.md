# Workflow designer (canvas)

## Designer

- `/dashboard/workflows/[id]` — designer: `designer.tsx` (reducer + undo/redo in `graphReducer.ts`, dirty tracking, debounced autosave flushed on unmount, Cmd/Ctrl+S save, Cmd/Ctrl+A select-all, Cmd/Ctrl+D duplicate, arrow-key nudge — burst coalesces into **one** undo step via ~500ms settle timer (`nudgeRef`/`flushNudge`: first press snapshots `before`, presses dispatch transient `moveNodes`, timer commits via drag path's `commitDrag`; flushed early by any non-arrow key action, selection change, or unmount before autosave unmount flush reads `graphRef`), Escape cancels active node drag), `canvas.tsx` (pan/zoom/marquee + pointer-type gesture split, zoom-to-fit on load + a bottom-right control cluster: the ⛶ fit button plus the agent-panel toggle), `node.tsx`, `edges.tsx`, `toolbox.tsx`. Placement is **free-form** — no grid snap, no dotted canvas background (`GRID` 24 survives only as the arrow-nudge/Cmd+D-duplicate step). **Canvas gestures** (`canvas.tsx`): bare left-drag on empty canvas **pans** (any pointer type; middle-drag + **space+left-drag** also pan — holding space shows `grab` cursor); on mouse/pen **shift+left-drag** = additive **marquee select**; bare left-click with no drag clears selection through `selectNodes` seam (edge selection clears too). Wheel zoom-to-cursor + trackpad (ctrl+wheel) pinch unchanged; two-finger touch pinch-zoom deferred. Space pan-modifier key handler skips form controls, `preventDefault`s space so it never scrolls page. **Escape double-fire avoided by phase**: `node.tsx` drag-cancel Escape listener registered `{capture: true}`, only `stopPropagation()`s while node drag actually active — designer bubble-phase Escape ladder skipped mid-drag (cancelling drag no longer also clears selection), idle Escape still reaches ladder. **Toolbox** (`toolbox.tsx`) = four tabbed groups — `blocks`/`apps`/`agents`/`models` (group id `apps`, label "Apps"; per-group entry lists built in `useMemo`s, not inline JSX) — over pinned bottom **variables** split. Search matches node's label, `key`, app/`group` name, `description`, config-field labels, server's tool names **across every group** (not just active tab): while query active each group tab shows match-count badge; if active tab has zero hits but another group has some, click-to-switch "N matches in {Group} →" hint jumps there. OpenRouter model list (hundreds of entries) filtered in `[models, q]` `useMemo`, count = plain `.length` — never run through other groups' match loops. Toolbox carries no hint lines (legend/wiring/one-event hints removed — wiring guidance lives on placed-node info popovers); event chips greyed by the one-event rule explain via hover `title` on the disabled chip; `agents` group's saturn section headingless. Variables split's `+ add` row stays visible even when query filters every secret out (empty state `no variables match "{q}"`), keeping 45% max-height. Toolbox drag-spawn drops route through `designer.tsx`, which toasts (`notify`) on three failure paths: drop outside canvas ("drop on the canvas to place the node"), dropping a github event node without a linked GitHub App ("link the GitHub App in settings to use GitHub events" — backstop, the toolbox chip is already disabled), or dropping second event node ("one event node per workflow — remove the existing one first"). `node.tsx`, `edges.tsx`'s `Edges` + per-edge path `React.memo`ized — node gesture handlers read live graph/selection through refs (`graphRef`/`selectionRef`), not props; keep new per-render props off `Node` or memo dies. `byKey` memo is keyed on the `\0`-joined set of node **types**, not `present.nodes` — a position-only change (every drag frame) must not mint a new `byKey`, or every `Node` memo breaks at once. Canvas's per-node derivation (`valueTargets`, `overriddenIds`, `outputOptions`, `reasoningOptions`, `outAnchor`) lives in one `nodeProps` `useMemo` keyed on `[graph, byKey, modelModalities, modelReasoning]` — nothing view-dependent belongs in it, or pan/zoom frames redo all the port geometry. Dirty tracking compares graph **references** (`present !== savedGraph`), not serialized JSON — an edit landing back on a JSON-identical graph stays dirty and costs one redundant autosave, which is the deliberate price of dropping a whole-document `JSON.stringify` per pointer event. Config fields with `overriddenBy` dim when port connected. **Edge-drag feedback honest**: during port drag, canvas `useMemo`s (deps = fixed drag ORIGIN + graph + byKey, never moving pointer) per-node map of port ids that would legally accept drag by running authoritative `canConnect` for every opposite-direction port, threads to each `Node` as comparable-string `connectable` prop (`""` no drag / `"-"` nothing connectable here / comma-joined connectable port ids — same memo-safe string pattern as `overriddenIds`/`outputOptions`); only genuinely connectable ports scale + glow, rest dim (illegal targets no longer lie). Port `<button>`s carry invisible `-inset-x-2 -inset-y-0.5` overlay span for ~26×14px hit target (vertical inset small — if-node l/in/r inputs sit only 16px apart, taller overlay would cross into neighbouring port; `data-port` stays on button so `elementFromPoint().closest("[data-port]")` drop resolution unchanged). Invalid drops surface terse toast via `notify` primitive (kind mismatch / wrong direction / self / accepts-port mismatch / chip-into-ordinary / duplicate / generic fallback — drop on empty canvas stays silent as cancel gesture); successful drop swapping single-edge value input toasts "replaced the existing connection" (still one undo step). **Edge selection**: clicking edge (invisible 12px "fat twin" hit path) **selects** — node + edge selection mutually exclusive (`selectedEdgeId` state in `designer.tsx`; every node-selection change routes through `selectNodes` wrapper clearing edge, `selectEdge` clears node selection). Hovered or selected edge wears emphasized stroke + circular **×** delete button at bezier midpoint, computed DOM-free from cubic control points (`(P0+3·P1+3·P2+P3)/8` in `edges.tsx` `curve`). Deletion = midpoint × or **Delete/Backspace** on selected edge (one undo step, `deleteEdge` action — undo restores); instant-delete-on-click gone. Escape clears edge selection (slotted into Escape ladder just above node-selection clear). **Topbar test-event runner** (`topbar.tsx`): right cluster all `text-xs` rounded-full controls — static amber-dot event label (one-event rule; `<select>` only for legacy multi-event graphs, schedules labelled by `describeCron`) + run button (`DeleteWorkflowButton` takes `sizeClass` prop, topbar passes `text-xs`); designer runs `runWorkflow` with `{ entryNodeIds: [selectedEventId] }`. Topbar runs-history link visible at every width (compact ↻ glyph below `sm`, full "runs" label from `sm` up; accessible name via `aria-label`). Clicking `schedule` node opens **cron popover** (`[id]/cronPopover.tsx`, hosts `CronBuilder` in callback mode, gated by `cronFloorMinutes` passed from page) writing `config.cron` as one undo step; node label strip shows `describeCron(config.cron)`. Clicking mcp server chip opens **tool-picker popover** (`[id]/toolPickerPopover.tsx`): checkbox per grantable tool (from entry's `tools`), writing node's `config.exclude` as one undo step per editing session. Cron, tool-picker, extract path-picker popovers share **`[id]/popoverShell.tsx`** — fixed `z-50` panel over `z-40` backdrop (closes on click, freezes canvas pan/zoom) with **measure-and-clamp-once** positioning (renders `visibility:hidden`, measures via `useLayoutEffect` + `getBoundingClientRect`, clamps fully into viewport with 8px margins, then freezes); each popover keeps own before-snapshot + `commitConfig` undo coalescing in `designer.tsx`. Extract path-picker samples port that actually feeds clicked config field — field's `overriddenBy` port when declared, else node's first value input (extract's `path` has no `overriddenBy`, so keeps sampling `value` input). **Live validation** runs in designer via `useDeferredValue(present)` + `useMemo(validateGraphStrict(deferredGraph, byKey, { githubLinked }))` (deferral = debounce; validator linear over graph capped at `MAX_NODES`; `githubLinked` derived from the `githubLink` prop threaded page→designer→toolbox so unlinked github event nodes warn), suppressed on empty graph so fresh workflow doesn't nag about missing event node. Topbar (not memoized) shows summary **badge** next to save status — red `✕ n` when any errors, else amber `⚠ n` — opening **issues panel** (`PopoverShell` anchored at badge) listing each issue (level icon + message); clicking issue carrying `nodeId` selects that node through `selectNodes` seam (stable `onSelectIssue` from designer), closes panel. `designer.tsx` also derives `issuesByNode: Map<nodeId, "error"|"warning">` (error wins) threaded to canvas, which passes each node comparable-string `issueLevel` prop; `node.tsx` renders small top-right colored **dot** (`issueDot.tsx`, red/amber, paint-only absolute overlay — top-RIGHT so never collides with top-left entry badge; NOT outline, which means selection) on every shape branch. Saves via `saveWorkflow` server action (validates UUID, `isWorkflowGraph` — unique node ids, edge endpoints exist — plus node/edge count caps + serialized-size cap; one-event rule = designer/`validateGraphStrict` semantic check, not part of this shape guard). **Embedded agent panel** (`[id]/agentPanel.tsx`): bottom-right canvas control (square robot button beside the ⛶ fit button, sharing its neutral chrome; `aria-pressed`, subtly filled while open — clicking it again closes) toggles a right-hand `<aside>` — last child of the Toolbox+Canvas row, so it sits right of the canvas and above the console — hosting `AgentChat panel` (from `app/dashboard/(shell)/agentChat.tsx`) with the open `workflowId`; left-edge pointer-capture drag resizes it (min 300px, max 0.6×`innerWidth`, local state, never persisted, mirrors `console.tsx`). A mount effect (never a lazy `useState` initializer — hydration) calls `takeHandoff(workflow.id)` and opens the panel when the dashboard chat handed this workflow over; the transcript itself needs no handing over — it lives in `agentChatStore` (below), still streaming. The chat's `g` frame lands via `onGraph`: `isWorkflowGraph`-validated, then `dispatch({type:"replaceGraph"})` (one undo entry) + `setSavedGraph` (server already persisted it, so autosave doesn't echo it back) + `notify("agent updated the graph")` — an agent save clobbers unsaved canvas edits, Cmd+Z recovers; an agent `update_workflow` rename doesn't live-update the topbar.
- `geometry.ts` = single source of truth for node metrics; `node.tsx` + `edges.tsx` must match exactly — edge anchors computed, never DOM-measured. Also exports `layoutGraph` (auto-placement for coordinate-less graphs, consumed by the hosted MCP server — see "Hosted MCP server"): the only import of this designer-local module from outside `workflows/[id]`, deliberate, since placement needs the same real sizes. Config rows per-field height (`configRowHeight`: `CONFIG_ROW_H` 36, textarea fields `TEXTAREA_ROW_H` 72 — `h-[72px]` row in `node.tsx`). Node box must never carry frame as real CSS `border`: ports anchor on border box (`node.x`/`node.y`), absolutely-positioned children anchor on padding box — border pushes every marker inward by its width, grows box past `nodeHeight()` — paint frames with `nodeFrame.tsx` inset overlay instead, hang perimeter ports off borderless outer box (see model/event branches). Port markers: flow ports filled diamond (45°-tilted square), value ports hollow `○`; both rotation-agnostic, no branch rotates them.
